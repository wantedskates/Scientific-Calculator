
## Main logic 
There will be the Base tables and then a consistent constructed table. What are the Base tables? Each table of the Base tables has two columns that maps the inputs and outputs of the Base functions that are :- 

$1$    $\log n$     $\sqrt{n}$    $n$    $n\log n$    $n^2$    $n^3$
$n^k$  $2^n$       $3^n$         $k^n$  $n!$         $n^n$

What is a consistent constructed table? It is a table with two columns that maps the test cases (input) and their results (output 
that is generated by the given code) but only considering output values that are smoothly ascending or descending without considering special cases
or violent jumps in output values.

There are 13 Base tables , let the set of them be $T$ with each table $t_1$ , $t_2$ ... $t_{13}$ , constructed table $C$ , rows 
of each one of the Base tables $r_n$ where $n is the number of test cases and rows of the constructed table $rc_n$ , define a function 
similarity   $sim( rc )$  that takes each row from $C$ and tells us which row from the Base rows that is much similar to it then each $t$ from 
the $T$ has a degree of similarity $d$ ( $0$  $\leq$ $d$ $\leq$ $n$ ) that increments by $1$ when $sim( rc )$ find it's row as the most similar row to 
the corresponding row in the constructed table. $sim( rc )$ iterates through all the rows of $T$ and the $t_i$ ( $1 \leq i \leq 13$ ) with 
the maximal value of $d$ is the most similar table to $C$ in which the complexity it maps is the answer that will be given to the user. 
This logic will be done for both the space and time complexity of the given code.
